# Лекториум

Локальный сервис для конспектирования лекций: загружаете аудиофайл или добавляете ссылку на YouTube и получаете расшифровку, краткий структурированный конспект и историю результатов.

**Стек:** Python, Hugging Face Transformers, FastAPI, PostgreSQL, S3-совместимое хранилище RustFS. Для упрощённого запуска поддерживаются SQLite и локальные файлы. Интерфейс написан на HTML/CSS/JavaScript.

## Возможности

- Загрузка аудио и распространённых контейнеров с аудиодорожкой: WAV, MP3, M4A, AAC, OGG, FLAC, OPUS, MP4 и WebM.
- Получение аудиодорожки публичного видео YouTube.
- Расшифровка на языке записи и конспект на русском языке.
- Просмотр исходного текста, очищенной расшифровки и фрагментов с приблизительным временем.
- Экспорт в Markdown, TXT и JSON.
- История задач, переименование и удаление завершённых результатов и записей с ошибкой.

По умолчанию размер записи ограничен 500 МиБ, длительность - четырьмя часами. Приватные видео, плейлисты и текущие прямые трансляции YouTube не поддерживаются.

## Как это работает

1. FastAPI сохраняет файл в хранилище и создаёт задачу в БД. Для YouTube скачивание выполняется в фоне.
2. Отдельный процесс **worker** забирает задачу. FFmpeg приводит аудио к mono WAV 16 кГц и делит его на фрагменты с перекрытием.
3. **Whisper large-v3-turbo** распознаёт речь; ответы фрагментов объединяются с удалением совпадений на стыках.
4. Whisper выгружается из памяти. **Qwen3.5-4B** очищает расшифровку и независимо создаёт конспект из сшитого ASR-текста. Для длинных записей формируются частичные конспекты и общий обзор.
5. Результат сохраняется в БД и появляется в интерфейсе. Закрытие вкладки не отменяет обработку; API и worker должны продолжать работать.

Модели запускаются на вашем компьютере. Первичная установка скачивает веса с Hugging Face; получение YouTube-аудио также требует сети. Аудио не отправляется во внешний сервис распознавания.

## Установка и первый запуск на Windows

Нужны Windows 10/11 x64, интернет для установки и скачивания моделей, FFmpeg и Node.js для YouTube. GPU-режим проверен на NVIDIA RTX 4060 Laptop с 8 ГБ VRAM и доступной CUDA. Веса занимают около 11 ГБ, временные части скачивания - ещё примерно 11 ГБ; дополнительно нужно место для окружения и аудио. Для CPU желательно от 24 ГБ RAM; полный запуск моделей на CPU не проверялся.

**1. Откройте PowerShell и установите инструменты:**

```powershell
winget install --id astral-sh.uv -e
winget install --id Gyan.FFmpeg -e
winget install --id OpenJS.NodeJS.LTS -e
```

**2. Откройте новый PowerShell в корне проекта**

Новый терминал нужен, чтобы установленные команды появились в PATH. Выполните команду:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
$env:UV_PYTHON = '3.12'
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1
```

Скрипт подготовит Python 3.12 и виртуальное окружение, установит зависимости, скачает обе модели и проверит контрольные суммы. Дождитесь сообщения `Ready`. Первая установка может занять значительное время; повторять её перед каждым запуском не нужно.

**3. Проверьте окружение и запустите сервис:**

```powershell
.venv\Scripts\python.exe scripts\doctor.py
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -OpenBrowser
```

Скрипт запустит API и worker в фоне и откроет браузер. При доступной CUDA модели используют GPU. По умолчанию новая копия хранит историю в SQLite, аудио - в локальных файлах; Docker для этого режима не требуется. Подключение PostgreSQL/S3 описано в [руководстве по запуску](docs/running.md).

- Интерфейс: [http://127.0.0.1:8080](http://127.0.0.1:8080).
- Документация API: [http://127.0.0.1:8080/docs](http://127.0.0.1:8080/docs).

## Повторный запуск

Откройте PowerShell в папке проекта и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -OpenBrowser
```

Если сервис уже работает, достаточно открыть страницу. Для перезапуска сначала выполните команду остановки ниже.

## Работа с интерфейсом

1. Выберите **«Аудиофайл»** или **«Ссылка YouTube»**, добавьте источник и укажите язык речи либо автоопределение.
2. Нажмите **«Создать конспект»**. Появятся текущий этап и прогресс.
3. По заверешние обработки, вы сможете тут же посмотреть конспект, расшифровку, исходный текст или фрагменты по времени. А также скачать результат в удобном формате.
4. В **«Истории»** выберите предыдущую запись. Переименование и удаление доступны после завершения обработки или ошибки. Подтверждённое удаление убирает исходное аудио и результат.

При ошибке задача остаётся в истории с сообщением. Подробности находятся в журнале worker. Отдельной кнопки повторного запуска нет: источник можно отправить заново.

## Остановка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop.ps1
```

Команда останавливает API и worker. История и аудиофайлы сохраняются. Принудительно прерванная задача может возобновиться после запуска worker и истечения аренды в очереди. Если используете PostgreSQL/S3 в Docker, контейнеры отдельно останавливаются командой `docker compose down`.
