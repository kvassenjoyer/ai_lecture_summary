# Лекториум

Локальный сервис для конспектирования лекций: загружаете аудиофайл или добавляете ссылку на YouTube и получаете расшифровку, краткий структурированный конспект и историю результатов.

**Стек:** Python, Hugging Face Transformers, FastAPI, PostgreSQL, S3-совместимое хранилище RustFS. Для упрощённого запуска поддерживаются SQLite и локальные файлы. Интерфейс написан на HTML/CSS/JavaScript.
